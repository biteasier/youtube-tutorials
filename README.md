# YouTube Tutorials: Automation Scripts

Free, ready-to-use scripts from my YouTube tutorials on **Power Automate**, **Power Apps**, **n8n** and **Mac automation** (AppleScript, Shortcuts, Numbers).

Each tutorial has its own folder with the script, a demo file to test it on, and step-by-step instructions.

YouTube: [@biteasier](https://www.youtube.com/@biteasier)

## Tutorials

| Tutorial | Platform | What it does | Video |
|---|---|---|---|
| [Export each Numbers sheet as a separate PDF](numbers-sheets-to-pdf/) | Mac · AppleScript | Exports every sheet of a Numbers file as its own PDF, named after the sheet | Coming soon |

## How to use

1. Open the tutorial's folder and read its README.
2. Try the script on the **demo file** first.
3. Then run it on a **copy** of your own files.

## Download

- **One file:** open the file on GitHub and click **Download raw file** (top right).
- **Everything:** click **Code › Download ZIP** at the top of this page.
