# YouTube Tutorials

Scripts and demo files from my YouTube automation tutorials: Mac automation (AppleScript, Shortcuts, Numbers, Pages, Mail) and Microsoft Power Automate.

Each tutorial has its own folder with the script, a demo file to try it on, and instructions.

## How to download

- **One tutorial:** open its folder, click a file, then use the download button (⤓) at the top right of the file.
- **Everything:** click the green **Code** button at the top of this page, then **Download ZIP**.
